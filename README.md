# Streamflow
Management for continuous flow estimates using Pressure Transducer (Level Logger) data.
You can find the scripts for each site in the scripts folders. Site two letter codes correspond to each five sites from the QuEST project. Other folders like "googledrive" and "data" are temporary data storing folders.


README.md                  Project overview, site list
streamflow.Rproj           RStudio project file
.R/ .DS_Store / .png       (auxiliary / generated files; ignore)
R/                         helper/analysis R code (completingAirPT.R)
scripts_nm/                Main processing pipeline for New Mexico sites (many numbered scripts)
data/                      Data directories (contains subfolders: PT, AirPT, formatted, compensated, raw, etc.)
pt_figs/                   PNG figures generated by scripts (plots of PT / compensated series)
.gitignore                 standard ignores
